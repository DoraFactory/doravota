## Recorded execution

Valid, unexpired IBC duplicate packets in both directions were rejected with channel/code 22 after a first successful receipt and fresh account sequence. No duplicate credit occurred. Test principal returned and commitments cleared; fees were accounted separately.

An empty-database non-validator state-synced height 17,269,200 (format 3, 51 chunks). Five nodes agreed at 17,269,717. All 112 distinct checksums represented by 156 on-chain Wasm code records were restored; extra old-format files were not counted as missing code.

A 350.33-second run completed 600 transfers and 9,228 balance queries. Loopback query p95 was approximately 2.83 ms; observed block intervals had median 2.313 s and maximum 2.685 s. This was not maximum capacity or 24-hour stability. Nine initially unavailable block-results queries later succeeded. Snapshot interval was increased from 100 to 1,000 test blocks after overlapping exports.

Some earlier checks used review5, not the final RC binary. After installing the exact AMD64 RC package on all five nodes, duplicate tests, old-contract queries, restart and 100 consecutive heights of hash agreement were repeated. ARM64 passed native CI execution, not a full ARM64 snapshot rehearsal.
